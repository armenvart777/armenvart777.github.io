# Сайт Армена Вартаняна

Личный сайт с услугами по разработке ботов, интеграций и автоматизации. В `index.html` находятся описания проектов и контакты, в `style.css` стили страницы. Для поисковых систем добавлены `robots.txt` и `sitemap.xml`.

Для просмотра откройте `index.html` в браузере. Сайт статический, сборка не требуется.
