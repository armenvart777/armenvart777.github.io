# Сайт Армена Вартаняна

Личный сайт с услугами по разработке ботов, интеграций и автоматизации. В `index.html` находятся верстка, стили, скрипт, описания проектов и контакты. Для поисковых систем добавлены `robots.txt` и `sitemap.xml`.

Для просмотра откройте `index.html` в браузере. Сайт статический, сборка не требуется.
